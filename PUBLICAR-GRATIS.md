# Publicar Lola gratis con GitHub Pages

Necesitas una cuenta gratuita de GitHub.

1. Entra en [github.com/new](https://github.com/new), inicia sesión y crea un repositorio llamado `lola` con visibilidad **Public**.
2. En la página del repositorio, pulsa **Add file** y después **Upload files**.
3. Arrastra los seis archivos de esta carpeta: `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js` y `README.md`. Pulsa **Commit changes**.
4. En el repositorio, abre **Settings** → **Pages**. En “Build and deployment”, elige “Deploy from a branch”, selecciona la rama `main`, la carpeta `/(root)` y pulsa **Save**.
5. Espera unos minutos. GitHub mostrará una dirección parecida a `https://tuusuario.github.io/lola/`. Ábrela primero en Chrome en tu Mac.
6. En el iPhone, abre esa misma dirección con Safari y usa **Compartir** → **Añadir a pantalla de inicio**.

GitHub Pages aloja esta web estática. No guarda conversaciones ni gestiona claves de IA.
